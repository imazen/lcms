# `lcms::lcms2` vs the official `lcms2` crate — public-API comparison

Companion snapshots:
- `lcms2-shim.txt` — the `lcms::lcms2` module surface (from `lcms.features.txt`,
  regenerated by `zenutils-apidoc` on `cargo test`)
- `lcms2-crate.txt` — the official `lcms2` crate 6.2.0 surface
  (`cargo public-api` on the crates.io copy)

The compat gate is `tests/lcms2_compat.rs` + `tests/lcms2_crate/mod.rs` — the
official crate's own 15 tests extracted verbatim (MIT credit), all passing.
The shim covers the tested tag/metadata + transform surface.

`Profile<C>` (all constructors + `read_tag`/`write_tag`/`has_tag`/`remove_tag`/
`info`/`icc`/`set_*`/`Debug`), `Transform<I,O>` (`new`/`with_flags`/

`new_device_link`), `Tag<'a>` (all 19 variants), `ToneCurve`/`ToneCurveRef`
(`Deref` split, `FloatOrU16`, `eval`/`estimated_gamma`/`smooth`/`reversed`/

## Intentional omissions (documented, not gaps)

- `transform_pixels_uninit` — `forbid(unsafe_code)` can't return `&mut [O]`
  over `MaybeUninit`. `transform_pixels` + `transform_in_place` are the safe
  equivalents.
- `as_ptr`/`from_ptr`/`as_ref`/`borrow`/`into_inner`/`drop`/`CType`/`Ref`/
  `Target`/`Owned`/`handle` — the `foreign-types` FFI wrapper family. A
  pure-Rust port has no raw handles; `Deref`/`DerefMut` cover the borrow
  shape.
- `*_context` constructors for `Profile<ThreadContext>` beyond
  `new_icc_context`/`new_file_context`/`new_srgb_context`/`new_lab4_context`
  — context generality maps to `Option<&Context>` internally (global vs
  thread context); the `GlobalContext`/`ThreadContext` generics carry it.

## Method-shape deviations (compat-visible, noted)

- `lcms::lcms2::Error` is an enum (`ObjectCreationError`/`MissingData`/
  `InvalidString`) matching `lcms2::error::Error`; the richer `LcmsError`
  (id + `signal_error` message) is kept alongside for detail.
- `*Ref` methods live on the aliased internal types (`named::Mlu`,
  `gamma::ToneCurve`, `lut::Pipeline`, `named::NamedColorList`) — the
  `lcms2::MLURef::set_text` name resolves through the alias; the snapshot
  lists the impl under the internal type's path.
- `Flags<F>` carries the cache marker (`AllowCache`/`DisallowCache`) as a
  type param; `Flags::default()` resolves to `Flags<AllowCache>`.

## Remaining gaps (enumerable, small)

- `Stage::new_clut_float_granular` (per-dim float CLUT — `clut_float_granular`
  exists internally; the wrapper wasn't added).
- `ToneCurveRef::reversed_samples`/`join`/`smooth` exist; `ToneCurveRef::
  estimated_entries`/`is_multisegment`/`is_descending`/`is_linear` exist —
  all present on the `gamma::ToneCurve` alias target.
- `Profile::new_device_link` takes `&mut Transform` semantics through the
  locked `Mutex<xform::Transform>` — the C-shape wrapper, not `&Plan`.
